# Data

Two open corpora: synthetic stories, educational web text. No code data, no Wikipedia.

Generated by `scripts/05_write_data_doc.py` from `meta.json`, written by the tokenizer pass.

## Sources and licenses

- TinyStories (https://huggingface.co/datasets/roneneldan/TinyStories): short synthetic stories, small vocabulary. License: CDLA-Sharing-1.0 (Community Data License Agreement, Sharing, version 1.0). Not gated.
- FineWeb-Edu (https://huggingface.co/datasets/HuggingFaceFW/fineweb-edu): web text filtered by an educational quality classifier, derived from Common Crawl. License: ODC-By 1.0 (Open Data Commons Attribution License version 1.0). Not gated.

## Downloads

- TinyStories: V2 GPT-4 variant (GPT-4 rewrite of the original GPT-3.5 corpus). Files: `TinyStoriesV2-GPT4-train.txt`, `TinyStoriesV2-GPT4-valid.txt`. Plain text, documents separated by `<|endoftext|>` marker line. Fetched directly from the dataset repository (V2 GPT-4 text not exposed as a loadable dataset config). Pool: 2,745,125 documents, 2,207,055,250 characters.
- FineWeb-Edu: streamed from `sample-10BT` config, stopped at 750,000,000 characters. Result: 157,616 documents, 750,005,218 characters. Prefix of the sample stream in dataset order, not a random sample.

Both domains normalized to JSON lines, one document per line, before tokenization. Raw text and tokenized output on external storage, not in this repository.

## Tokenizer

- Byte-level BPE, vocabulary 16,384, trained on this mixture. Training sample drawn in proportion to the intended token mix, striding through each corpus to span the whole of each source. Full byte alphabet in the initial vocabulary: any input round-trips exactly, including characters the trainer never encountered.
- `<|endoftext|>`: only special token, id 0, separates documents in the token streams.
- Stored at `data/tokenizer/tokenizer.json`, version controlled with the code. SHA-256: `5caa638a1c34d87da9febe64e25f664b6d99f9a4b476f8890b1069e6ba679674`.

## Split protocol

- Splits made by document, never by cutting a token stream at an arbitrary position.
- Holdout documents chosen and tokenized before the training stream is built. Seeded random draw marks a candidate pool per domain; candidates fill validation to about 5.0M tokens, then test to about 5.0M tokens (real tokens, not estimated from characters). Leftover candidates released back to training; remaining documents streamed into the training file. Seed: 20260717, reproducible.
- A document belongs to exactly one split; no text shared between training and evaluation.
- Windows may cross document boundaries within a split; documents joined by the separator token. A window spanning a boundary inside the validation stream contains only validation documents.

## Web extension

Base FineWeb-Edu train stream: 167,948,480 tokens. Staged run draws 30 percent of a multi-billion-token budget from the web domain. Extension continues `sample-10BT` past the same document prefix, tokenized into additional train-only shards.

Registered 200-gram leakage check fired on the extension: `sample-10BT` contains near-duplicate documents of the held-out documents; the original slice was clean only because holdout documents were excluded from exactly that prefix. Extension produced by `scripts/13_filter_ext.py`, dropping any extension document whose tokenized form shares a 200-token n-gram with the closed val or test stream. Gate results in `docs/DECONTAMINATION.md`.

## Reproducing

Numbered scripts, in order: `02_download.py` (raw corpora), `03_train_tokenizer.py` (tokenizer), `04_tokenize.py` (token streams, `meta.json`), `05_write_data_doc.py` (this file). Download step resumable, skips domains already complete on disk.

Web extension, separate pass: `02_download.py --extra-web-tokens 2.5e9` (continuation), `13_filter_ext.py` (tokenize and decontaminate into train-ext shards), `12_leakage_check.py --domain fineweb_edu --extension` (registered gate result). Neither corpus redistributed here; both fetched from source by these scripts.
